# Pearl & Pour

My boba website for Hack Club's Boba Drops. It's all HTML and CSS, no JavaScript.

I wanted a page that felt like me, so it's about the drinks I actually order. The cup drawing is an SVG I made myself.

## Files

- `index.html` is the whole site
- `style.css` has all the styling
- `boba.svg` is the cup drawing

## What's in it

HTML: header, nav, main, sections, articles, a figure with a caption, an image with alt text, a table, ordered and unordered lists, `<details>` for the FAQ (it opens and closes without JS), a blockquote, `<mark>`, `<strong>` and `<em>`, and anchor links between sections.

CSS: custom properties for colors, flexbox, grid, a keyframe animation on the cup, hover transitions, a dotted background made with a gradient, box shadows, rounded corners, `::before` content, striped table rows, and media queries for phones and for people who turn off animations.

I kept the font big (18px) and the text dark on a light background so it's easy to read.

## Run it

Open `index.html` in your browser.
